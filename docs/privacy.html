Privacy Policy

Effective date: August 26, 2026

This Privacy Policy describes how the PDKS Time Calculator browser extension handles information.

Information processed

When the user requests a refresh, the extension reads attendance records visible on the active ARGEPORTAL PDKS page. These records can include punch timestamps, worked durations, and leave-related values. The extension processes this information solely to calculate and display working-hour summaries.

Local storage

Calculated snapshots, user preferences, leave and out-of-office values, and the user-configured portal address are stored locally using the browser's extension storage. This information remains on the user's device until the user clears the extension's storage or removes the extension.

Data transmission and sharing

Attendance records and locally stored settings are not sent to the developer or to a third-party analytics service. The extension makes a request to the public GitHub repository only to check the latest available extension version. No attendance data is included in that request.

The extension does not sell, rent, or share user information for advertising, profiling, or other commercial purposes.

Browser permissions

The extension uses active-tab and scripting permissions to read the PDKS page only after user interaction, and storage permission to keep the local data and preferences described above.

Google user data

The installed browser extension does not request access to an end user's Google account or Google user data. Google OAuth credentials used by the project owner are used only by private release automation to upload extension packages to the Chrome Web Store.

Changes to this policy

Material changes to this policy will be published on this page and reflected by an updated effective date.

Contact

Privacy questions can be submitted through the project's GitHub issue tracker.
